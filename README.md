# Project Cost Calculator

Простий десктопний калькулятор вартості проєкту: QA, Dev 1, Dev 2, Content Manager. Для кожної ролі вказуєте години та рейт ($/год), додаєте буфер у відсотках і бачите підсумок.

## Встановлення (macOS)

1. Відкрийте розділ **Releases** цього репозиторію.
2. Завантажте `.dmg`: `arm64` для Mac на Apple Silicon (M1–M4), `x64` для Intel.
3. Відкрийте `.dmg` і перетягніть програму в «Програми».

### Попередження macOS «неможливо перевірити розробника»

Програма не підписана платним сертифікатом Apple, тому при першому запуску macOS її блокує. Це одноразова дія:

**Спосіб 1.** Спробуйте відкрити програму, потім: Системні налаштування → Конфіденційність і безпека → внизу натисніть **«Все одно відкрити»**.

**Спосіб 2.** У Терміналі:

```bash
xattr -cr "/Applications/Project Cost Calculator.app"
```

## Встановлення (Windows)

Завантажте `.exe` з Releases і запустіть. Якщо SmartScreen попереджає: «Докладніше» → «Виконати в будь-якому разі».

## Запуск із коду

Потрібен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm start
```

## Збірка інсталятора локально

```bash
npm run dist
```

Готові файли з'являться в папці `dist/`.

## Публікація релізу

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions збере `.dmg` і `.exe` та додасть їх до Releases.
